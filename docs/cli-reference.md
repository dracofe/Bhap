# CLI reference

_Generated by `scripts/gen_cli_reference.py` — do not edit by hand._

Bare `bhap` (or `bhap chat`) opens the interactive session; type `/help` inside it.

Global options (accepted anywhere on the command line): `-w/--workspace`, `--lang id|en`, `--no-color`, `-q/--quiet`. Environment: `BHAP_HOME`, `BHAP_LANG`, `BHAP_OLLAMA_URL`, `BHAP_LLAMACPP_URL`, `NO_COLOR`, `BHAP_BACKUP_PASSPHRASE`.

```text
usage: bhap [-h] [-V] [-w WORKSPACE] [--no-color] [--lang {id,en}] [-q] <command> ...

Bhap — a private knowledge assistant that runs offline in your terminal.

positional arguments:
  <command>
    chat                interactive session (same as `bhap`)
    setup               choose/download local models (downloads only with consent)
    doctor              diagnostics & offline readiness
    status              engine, storage, model, workspace status
    workspace (ws)      manage workspaces
    add                 import PDF/DOCX/PPTX/MD/TXT
    docs                manage documents
    open                preview a source by chunk id
    ask                 one-shot question (script friendly)
    search              search source passages (hybrid)
    summarize           source-grounded summary
    compare             compare two documents (differences & contradictions)
    study               study: quizzes, flashcards, tutor, progress
    notes               source-linked notes
    history             local conversation history
    model               list/choose/download local models
    backup              portable packs: backup/restore
    app                 open the Bhap desktop app (window)
    graph               knowledge map: documents → sections → shared concepts
    jobs                indexing jobs (restart safe)
    watch               watch folders & index changes
    config              local settings
    logs                structured local logs
    version             version and platform

options:
  -h, --help            show this help message and exit
  -V, --version         show program's version number and exit
  -w, --workspace WORKSPACE
                        workspace to use
  --no-color            disable colors (also NO_COLOR=1)
  --lang {id,en}        interface language
  -q, --quiet           fewer progress messages

examples:
  bhap                                   open the interactive session (cd, paste file paths, ask)
  bhap doctor --offline                  offline readiness check
  bhap workspace create uni --use        create & activate a workspace
  bhap add ./notes --recursive           import a folder (preview + confirmation)
  bhap ask "What is normalization?" --sources
  echo "What is an ERD?" | bhap ask --stdin --json
  bhap study quiz "Dijkstra" --count 5
Exit codes: 0 ok · 2 invalid usage · 3 model/runtime not ready · 4 parse failure · 5 database · 130 cancelled
```
